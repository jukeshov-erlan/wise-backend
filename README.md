# WISE Backend

Бэкенд платформы WISE для сопровождения студентов при поступлении в зарубежные университеты.

Стек: Java 21, Spring Boot 4, PostgreSQL 17, Flyway, Maven, Docker.

## Что нужно установить

- JDK 21
- Docker Desktop
- Git

## Запуск на своём компьютере

1. Скопировать файл с переменными окружения:

   ```
   cp .env.example .env
   ```

2. Запустить базу, почту и хранилище файлов:

   ```
   docker compose up -d
   ```

   Проверить, что всё работает: `docker compose ps`. У `wise-postgres` должен быть статус `healthy`.

3. Запустить приложение:

   ```
   ./mvnw spring-boot:run
   ```

4. Проверить: открыть http://localhost:8081/actuator/health, ответ должен быть `"status":"UP"`.

Остановить приложение: `Ctrl+C`. Остановить контейнеры: `docker compose down` (данные сохраняются).

## Порты

Порты выбраны так, чтобы не пересекаться со стандартными, которые часто заняты другими проектами.

- `8081` — приложение (на сервере `8080`)
- `15432` — PostgreSQL
- `1025` — Mailpit, приём писем от приложения
- `8025` — Mailpit, веб-интерфейс: http://localhost:8025
- `9000` — RustFS, хранилище файлов (S3 API)
- `9001` — RustFS, веб-панель: http://localhost:9001/rustfs/console/

## Тесты

```
./mvnw verify
```

Перед запуском тестов контейнеры должны быть запущены (`docker compose up -d`).

## Профили

- `local` — запуск на своём компьютере, включается по умолчанию
- `test` — автоматические тесты
- `prod` — сервер, все значения только из переменных окружения

## Модули

Код разделён на модули, каждый в своём пакете внутри `com.wise`:

- `identity` — вход, токены, роли и права доступа
- `profiles` — студенты, кураторы, группы
- `academic` — оценки, экзамены, активности, награды
- `applications` — университеты и заявки
- `goals` — цели, этапы, индивидуальный маршрут
- `assignments` — каталог и назначение заданий
- `submissions` — сдача и проверка работ
- `documents` — файлы, документы, эссе
- `deadlines` — дедлайны и просрочки
- `issues` — проблемы студента и заметки
- `resources` — библиотека материалов
- `notifications` — уведомления и письма
- `admin` — дашборды и отчёты
- `audit` — журнал действий
- `common` — общее для всех модулей (ошибки, настройки, базовые классы)

Пакет модуля создаётся вместе с его первым классом.
